# Development Roadmap

`PROJECT_PLAN.md` is the authoritative execution roadmap and gate record. Work proceeds in dependency order from foundation and database through security and production review.

Each meaningful task follows read → plan → implement → verify → fix → verify → document → mark complete → advance current task. A feature is complete only when its applicable UI, API, validation, authorization, business logic, persistence, transactions, error handling, auditability, and tests are real and verified.
